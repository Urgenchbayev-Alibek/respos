RestaurantOS — Product Design: макеты

Статичные wireframe-макеты на токенах из DESIGN_SYSTEM.md. Без внешних зависимостей.

Admin dashboard

Sidebar из 18 разделов, KPI за сегодня, популярные блюда, низкие остатки, статус смены.

Создание заказа (планшет)

Рабочее место официанта: категории, сетка блюд, панель заказа стола, отправка на кухню.

Kitchen Display (KDS)

Тёмный экран кухни: колонки статусов, таймеры ожидания, крупные кнопки, индикатор связи.

Касса: оплата

Смена, активные заказы, частичная оплата, способы оплаты, сдача, демо/нефискальные пометки.

Склад: ингредиенты

Фильтры, таблица остатков с подсветкой ниже минимума, действия, пустое состояние, модалка корректировки.

Claude Design в этой сессии недоступен — макеты подготовлены вручную как HTML-wireframes (см. DESIGN_BRIEF.md).
